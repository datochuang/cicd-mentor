# 日誌一筆

```
schema: log/1
```

每個動作、每則送出的訊息、每個判斷一筆；寫看了什麼、推論什麼、不確定什麼。在工作區 `designs/<名>/log/`，團隊可讀；不放 design 內容；重啟後從這裡接續（動作之前先查有沒有做過）。

```
時間: 2026-10-09T14:02
實例: agent-dma v0.3.2
類別: 觀察 ／ 判斷 ／ 訊息 ／ 動作 ／ 請示 ／ 更正
對象: //depot/chipA/dma ／ CL 48990 ／ 王小明
看了什麼: CL 48990 的說明與 12 個檔的清單
推論: 說明「update」看不出目的；一包 12 個檔含 rtl 與 script
不確定: 是不是 wip 包
做了什麼: 私訊 CL 作者，附改寫的說明示範；記進狀態板「等回」
依據: Small batches；版控常規「說明寫目的」
結果: （之後補）10-09 15:10 作者回：是 wip，下次拆
```

## 不寫的

- design 的內容（RTL、netlist、波形）。
- 個人的活動量統計。
