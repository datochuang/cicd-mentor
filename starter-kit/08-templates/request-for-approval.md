6. **要 PM 回答的兩個問題**（用來確認懂了）

   - 問題二：
7. **第一次出現的概念**：各一句解釋＋投影片的頁碼

## 示意

**要做什麼**：把 dma 的 sanity check 從「只報告」升到「警告」。

**掛哪個原則**：CI——改壞的那一包進來時就被標出來；目前只報告，三週 42 次跑、2 次誤報（都是 lib 路徑，已修）。

**影響誰**：submit 到 //depot/chipA/dma/ 的人會在 CL 上看到警告，不會被擋；owner 王小明已同意；下游 top 不受影響。

**不做會怎樣**：結果只在報告頁，沒人看；替代：繼續只報告一個月（不選：誤報已壓到 0 兩週）。

**怎麼退回**：trigger 設定改回 report 級，PM 或 admin 一行指令；kill switch 也關得掉。

**要 PM 回答的兩個問題**：
- 警告級的 check 不過，工程師的 submit 會不會被擋？
- 誰看得到這些警告？

**概念**：只報告／警告／擋——check 的三種上線等級（《互動場景》第 8 頁）。
