# 盲讀驗收：《agent 的基本模塊》標題（2026-10-10）

方法：派乾淨 context 的 subagent，只給文件標題與八頁標題，扮演「每天用 Perforce、不熟 CI/CD、沒參與討論」的 RTL 工程師。以下是報告摘要與處理。

## 第一輪（初版標題）

初版文件標題：「agent 的基本模塊：能力拆成以契約描述的模塊，公司專屬的只有三種綁定，沙盒驗契約」

讀者的發現（按嚴重度）：

1. **三個核心詞沒定義，且和 IC 用語撞**：「契約」不知是 spec 還是 interface；「綁定」會想到 RTL 的 `bind`；「三態」一定讀成 tri-state；「模塊」第一反應是 Verilog module。
2. **主詞缺席**：八頁都看不出「誰拆、誰看、誰驗、誰核准」；第 5 頁「理解後核准」兩個動作主詞不同，意思相反（人核准 vs agent 自己核准）。
3. **數字對不上**：十七個模塊從標題只加得出 13（第 6 頁沒給數字）；「三種綁定」八頁沒有一頁點名是哪三種；「十個階段」第一次出現沒說是誰的階段。
4. **第 7 頁自相矛盾**：前面說公司專屬是「三種綁定」，這頁說「換一張評分表就能用」，讀者不知道公司專屬到底是綁定還是評分表。
5. **「有和沒有模塊化差在哪」從標題看不出**：沒有一頁講「不拆會怎樣」。
6. **公司沒有的詞**：MR（會猜 Modification Request）、分級上線（IC 公司沒有「上線」）、守門機制、目標（指 depot 時）、單位。
7. **第 8 頁沒有「所以」**：「沒有一個階段用到全部」看不出為什麼值得當結論。
8. 第 2–5 頁「看／判／做／說」單字開頭看得出是一套，但沒有一頁說這是 agent 的動作；第 6 頁「守與養自己」格式斷掉。

讀者寫出的主張版本：「這個自動化工具被拆成十七個小單元，每個單元有一份規格；跟我們公司綁死的部分只有三個接口，其他地方換掉某張表就能搬去別處用。」——方向對，但他自己說是硬湊的。

## 處理

| 讀者的發現 | 改法 |
|---|---|
| 契約 | 全文改「規格」（IC 的 spec 類比：講它保證什麼，不講怎麼做）；第 1 頁定義框註明「軟體說的 contract」 |
| 綁定 | 改「公司專屬的三樣」，並在第 1、7 頁與文件標題點名：接 depot 的程式、評分表、規矩表 |
| 三態 | 改「三種結果：過／不過／探測本身壞了」 |
| 模塊 | 第 1 頁定義框加「和 design 的 module 無關」；「agent」加一句「自主運行的 AI 程式」 |
| 主詞缺席 | 每頁標題補 agent 當主詞；第 5 頁改「PM 看懂才核准」 |
| 數字 | 第 6 頁改「守：四個模塊」，4+3+3+3+4＝17；第 1 頁膠囊同步；第 8 頁改「mentor agent 的十個階段」 |
| 第 7 頁矛盾 | 評分表是三樣之一；標題改「公司專屬的只有接 depot 的程式、評分表、規矩表；換掉就是別的 agent」 |
| 有／沒有 | 第 1 頁標題後半改「沒拆就搬不走、驗不了哪裡錯」 |
| MR | 內文改「review（MR）」，標題改「改自己先過沙盒」 |
| 分級上線／守門機制 | 模塊改名「逐級收緊」（和《互動場景》的階段名「上線分級」區分）；標題寫白話「任何 check 先只報告，有共識才擋」 |
| 目標／單位 | 指 depot 時寫 depot；「單位」改「目錄」；「單位的規矩登記」改「目錄的規矩登記」 |
| 第 8 頁的「所以」 | 標題改「所以模塊能分開做、分開驗」 |
| 看判做說守 | 第 1 頁註明「看判做說守是 agent 的五種動作」；第 6 頁改「守：…」 |

沒採納的：讀者猜的三種接口「接 depot、接通知、接 build」是他的猜測，實際三樣是接 depot 的程式、評分表、規矩表，已照實際點名。

## 改後的標題

- 文件：agent 的基本模塊：拆成十七個各有規格的模塊，公司專屬的只有三樣
1. 總覽：agent 拆成模塊，各一條只講性質的規格；沒拆就搬不走、驗不了哪裡錯
2. 看：agent 用四個模塊認識 depot，每條觀察附出處，猜的不能當依據
3. 判：agent 用三個模塊照評分表打分，每條附檢驗、重現要能辨認結果、不排名
4. 做：三個模塊讓 agent 把沒過的檢驗寫成提案；任何 check 先只報告，有共識才擋
5. 說：三個模塊管 agent 和人的互動：PM 看懂才核准、不濫發訊息、動作留紀錄
6. 守：四個模塊管住 agent：規矩明寫、範圍先登記、改自己先過沙盒、花費有上限
7. 接公司：公司專屬的只有接 depot 的程式、評分表、規矩表；換掉就是別的 agent
8. 組裝：mentor agent 的十個階段各挑幾個模塊，所以模塊能分開做、分開驗
