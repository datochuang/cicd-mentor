4. **CLAUDE.md 紅線「不 submit 到共用路徑（授權表明寫可以的除外）」vs 05 #13、09 #5、config.md「不 submit 任何東西」**：隱含 submit 到非共用路徑可以。身分段「只讀」和「要 shelve 時加寫入」「owner 授權 trigger 直接寫」三者擺在一起會問「到底要不要寫入權限」。建議紅線改「不 submit 任何東西（授權表明寫的例外除外）」；身分段改「只讀 depot，交東西只用 shelved CL」。
